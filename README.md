# AETHON — Multipage website (corrected package)

Upload all root HTML/CSS/JS files to the root of your GitHub repo. Upload the files from `assets/` to the repo `assets/` folder.

## Required files
Root: index.html, agents.html, solutions.html, about.html, docs.html, contact.html, demo.html, style.css, app.js, README.md.
Assets: assets/logo.webp, assets/hero.webp, assets/atmosphere.webp.

The HTML and CSS reference `.webp` images consistently. The favicon uses logo.webp. The extra atmosphere.webp is included for future design updates.

Enable GitHub Pages in Settings > Pages > Deploy from a branch > main > / (root).

This is a front-end concept website. Demo is a local simulation, not live AI.
